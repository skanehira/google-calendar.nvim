# 予定の登録

- 種別: 機能設計書
- 対象 UC: UC-002 (docs/design/USECASES.md)

## 何を作るか

月表示で選んだ日を初期値として予定の登録フォームを開き、タイトル・開始/終了日時・場所・説明・終日・Google Meet の有無を入力して `gws` で予定を作成する。作成後は表示中の月を再取得し、作成した予定を月表示に反映する。Meet を有効にした場合は `gws calendar +insert --meet` で会議 URL を作成する。

## 入出力と振る舞い

**フォームのレイアウト**:

Google カレンダーの作成ダイアログ風のメインウィンドウと、項目ごとのエディタウィンドウを組み合わせる。

```text
╭─ 新しい予定 ──────────────────────────────────────────────╮
│ タイトルと日時を追加                                      │
│ ───────────────────────────────────────────────────────── │
│                                                            │
│ ◷ 10月28日 (水曜日)・09:00〜10:00  [終日]                 │
│ ◉ ゲストを追加                                             │
│ ▶ Google Meet のビデオ会議を追加  [off]                   │
│ ⌖ 場所を追加                                               │
│ ☰ 説明または Google ドライブの添付ファイルを追加          │
│ ▣ primary                                                  │
│                                                            │
│ その他のオプション  [保存]  <F2>:保存  <Tab>/<S-Tab>:移動  │
╰────────────────────────────────────────────────────────────╯
```

タイトル・日時・場所・説明・ゲストの行で `<CR>` を押すと、それぞれ専用のエディタウィンドウが開く。日時エディタは開始・終了・終日の 3 行を持ち、`<CR>` で日時フィールドを編集、`<Space>` で終日を切り替え、`<F2>` で適用する。

**操作 → 振る舞い**:

| 操作 | 振る舞い |
| --- | --- |
| 月表示で `a` | 選択日を開始日とした登録フォームを開く。開始 09:00、終了 10:00、終日 off、Meet off |
| `<Tab>` / `<S-Tab>` | メインウィンドウの次の行 / 前の行へ移動する |
| `<CR>` | タイトル・日時・場所・説明・ゲストのエディタを開く。Meet 行では Meet をトグルする |
| `<Space>` | 日時行では終日を、Meet 行では Meet をトグルする |
| `<F2>` | 入力を検証し、問題なければ `gws` で作成する |
| `<Esc>` / `q` | フォームを閉じ、入力と作成を破棄する（`<Esc>` は insert モードでは insert を抜けるだけで、normal モードでキャンセルする。`q` は normal モードのみ） |
| `?` | フォームのヘルプを開く（[help.md](help.md)） |
| エディタで `<CR>` | 日時エディタの選択フィールドを編集する |
| エディタで `<F2>` | エディタの値をフォームへ適用して閉じる |
| エディタで `<Esc>` / `q` | 値を適用せずにエディタを閉じる |

ゲスト行からゲストのメールアドレスを追加できる。1 行に 1 アドレスを入力し、重複は除外、不正な形式は通知する。

**入力項目**:

| フィールド | 必須 | 形式 | 既定値 |
| --- | --- | --- | --- |
| タイトル | はい | 1〜1024 文字 | 空 |
| 開始 | はい | `YYYY-MM-DD HH:MM`（終日は `YYYY-MM-DD`） | 選択日の 09:00 |
| 終了 | はい | `YYYY-MM-DD HH:MM`（終日は `YYYY-MM-DD`） | 選択日の 10:00 |
| 終日 | いいえ | on / off | off |
| 場所 | いいえ | 0〜1024 文字 | 空 |
| 説明 | いいえ | 0〜8192 文字 | 空 |
| Meet | いいえ | on / off | off |
| ゲスト | いいえ | メールアドレス（1 行に 1 件） | 空 |

**検証**:

- タイトルが空、または 1024 文字を超える場合はエラー
- 日時が `YYYY-MM-DD HH:MM` として解釈できない場合はエラー
- 終了が開始以前の場合はエラー
- 終日の場合、終了日が開始日以前の場合はエラー（API の `end.date` は排他）
- エラー時はフォーム内のフッターにエラーを表示し、該当フィールドを `GoogleCalendarError` でハイライトする。`gws` は呼ばない

**gws の呼び出し**:

- 時刻付き予定:
  ```text
  gws calendar +insert --summary <title> --start <RFC3339> --end <RFC3339>
    [--location <location>] [--description <description>]
    [--attendee <email>]... [--meet]
  ```
- 終日予定:
  ```text
  gws calendar events insert --params '{"calendarId":"primary"}'
    --json '{"summary":...,"start":{"date":"YYYY-MM-DD"},"end":{"date":"YYYY-MM-DD"},...}'
  ```
- `cwd` はキャッシュディレクトリ（[DESIGN.md](../DESIGN.md)「既知の制約」）
- 成功時はフォームを閉じ、月表示を再取得し、`予定を作成しました` と通知する
- Meet 有効時は応答の `hangoutLink` を予定モデルに含める。`hangoutLink` が無い場合は「予定は作成されたが Meet URL が付かなかった」旨の警告を出す

キーマップは `config.keymaps.form` から解決し、`setup()` で上書きできる。保存の既定キーは `<F2>`（`<C-s>` は herdr の prefix と衝突するため使わない）。

## API

該当なし（HTTP API を持たない。`gws` の呼び出し規約は [DESIGN.md](../DESIGN.md)「CLI インターフェース」「既知の制約」参照）。

## 実装の配置

| 処理 | 層 | 実装先ファイル |
| --- | --- | --- |
| 登録フォームの描画・入力・検証 | UI | `lua/google-calendar/ui/form.lua` |
| 日時のパースと RFC3339 変換、終日日の加算 | ドメイン | `lua/google-calendar/calendar.lua` |
| 予定モデルの組み立て、応答の正規化 | ドメイン | `lua/google-calendar/event.lua` |
| `+insert` / `events insert` の実行（アダプタの `create_event` を呼ぶ） | アダプタ | `lua/google-calendar/gws.lua` |
| 成功・失敗・Meet 失敗の通知（アダプタの通知を使う） | アダプタ | `lua/google-calendar/notify.lua` |
| 作成後の月表示の再取得 | UI | `lua/google-calendar/ui/month_view.lua`（`open_create` がフォームへ再取得コールバックを渡す） |

作成した予定の Meet URL の詳細表示は [event-detail.md](event-detail.md)、終日予定の月表示は [month-view.md](month-view.md) が担う。本機能は作成された予定モデルに `hangout_link` / `start.date` が入ることを保証する。

## エッジケースの決定

- **空・最小データ**: タイトルが空のまま保存できない。場所・説明は空でも作成できる。選択日が今日の場合も既定値は 09:00〜10:00 とする
- **上限・境界値**: タイトル 1024 文字、説明 8192 文字を上限とする。日付は 1 月 1 日〜12 月 31 日、時刻は 00:00〜23:59 を扱う。終日予定の終了日は開始日 + 1 日以上とする。月をまたぐ予定も作成できる
- **エラー時に利用者へ見えるもの**: 検証エラーはフォーム内に表示する。gws のエラーはフォームを閉じずにフッターへ表示し、入力値を保持する。Meet 失敗は予定の作成成功として扱い、警告だけを出す
- **並行操作・二重実行**: 保存中は `<F2>` を無効化し、`保存中...` を表示する。フォームを開いたまま月表示の再取得が走っても、フォームの内容は保持する
- **再表示時の整合**: 作成後に表示中の月を再取得する。作成した予定が表示範囲外（例: 翌月）の場合は、現在の月表示には現れない旨を通知に含める
