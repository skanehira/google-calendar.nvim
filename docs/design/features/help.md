# キー操作のヘルプ

- 種別: 機能設計書
- 対象 UC: UC-006 (docs/design/USECASES.md)

## 何を作るか

月表示・日別アジェンダ・詳細・登録/更新フォームのそれぞれで `?` を押すと、その画面で有効なキーの一覧を float window に表示する。ヘルプの内容は `setup()` で変更したキーマップを反映する。`q` / `<Esc>` でヘルプを閉じ、元の画面に戻る。ウィンドウの幅・高さは表示行に合わせ、下部・右側に空白を残さない。

## 入出力と振る舞い

**操作 → 振る舞い**:

| 操作 | 振る舞い |
| --- | --- |
| 月表示で `?` | 月表示のキー一覧を開く |
| アジェンダで `?` | アジェンダのキー一覧を開く |
| 詳細で `?` | 詳細のキー一覧を開く |
| フォームで `?` | フォームのキー一覧を開く |
| ヘルプで `q` / `<Esc>` | ヘルプを閉じ、元の画面に戻る |

**ヘルプの内容（既定）**:

| 画面 | キー |
| --- | --- |
| 月表示 | `h/l`:前日/翌日、`k/j`:前週/翌週、`H/L`:前月/次月、`t`:今日、`<CR>`:アジェンダ、`a`:登録、`r`/`R`:再取得、`?`:ヘルプ、`q/<Esc>`:閉じる |
| アジェンダ | `j/k`:選択、`<CR>`:詳細、`q/<Esc>`:戻る |
| 詳細 | `e`:更新、`d`:削除、`y`:Meet URL コピー、`q/<Esc>`:戻る |
| フォーム | `<Tab>/<S-Tab>`:移動、`<CR>`:編集、`<Space>`:切替、`<F2>`:保存、`q/<Esc>`:取消（`<Esc>` は normal モード） |

**表示**:

- ヘルプは現在の画面の上に重ねて開く。既にヘルプが開いている場合は再使用する
- ヘルプのサイズは `width = min(70, columns - 8)`、`height = min(#lines + 4, 20)`
- キーの表記は `setup()` の `keymaps` を反映する。`false` で無効化したキーは表示しない

キーマップは `config.keymaps` から解決し、`setup()` で上書きできる。ヘルプは解決後のキーを表示する。

## API

該当なし（HTTP API を持たない）。

## 実装の配置

| 処理 | 層 | 実装先ファイル |
| --- | --- | --- |
| 画面ごとのキー一覧の生成と描画 | UI | `lua/google-calendar/ui/help.lua` |
| 既定キーマップと `setup()` の上書きの解決 | 設定 | `lua/google-calendar/config.lua` |
| ヘルプの float の生成・破棄 | UI | `lua/google-calendar/ui/window.lua` |
| 各画面の `?` キーマップ（月表示・アジェンダ・詳細・フォーム） | UI | `lua/google-calendar/ui/month_view.lua` / `agenda.lua` / `detail.lua` / `form.lua` |

## エッジケースの決定

- **空・最小データ**: 有効なキーが 1 つもない画面では `有効なキーがありません` と表示する
- **上限・境界値**: キーが多い場合はスクロール可能にする。ヘルプの行数が画面を超える場合は `j` / `k` でスクロールする
- **エラー時に利用者へ見えるもの**: ヘルプはローカルの情報だけで、API エラーは起きない。別の float が開いていて重ねられない場合は、既存の float を閉じてからヘルプを開く
- **並行操作・二重実行**: ヘルプは 1 つだけ開く。既に開いている場合はフォーカスする
- **再表示時の整合**: `setup()` の変更後に開いたヘルプは最新のキーマップを表示する。実行中にキーマップを変更した場合は、次にヘルプを開いたときに反映する
