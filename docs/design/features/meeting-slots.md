# オンライン MTG の空き枠候補

- 種別: 機能設計書
- 対象 UC: なし（UC 定義後の追加機能。docs/design/USECASES.md には未記載）

## 何を作るか

オンライン MTG の日時候補を相手に送るために、選んだ週の空き時間を一覧にして、`y` でテキストとしてコピーできるようにする。候補を選ぶと、その日の予定がタイムラインに並ぶ。利用者は前後の予定（移動が要る予定など）を見て、候補が使えるかを判断できる。

流れは 2 画面で構成する。

1. **条件選択**: 時間帯・所要時間・週を選ぶ。時間帯と所要時間は 1 つ、週は複数選べる
2. **候補一覧**: 左に候補の一覧、右に選択中の候補の日のタイムラインを並べて表示する

## 入出力と振る舞い

**入口**:

| 操作 | 振る舞い |
| --- | --- |
| `:GoogleCalendar slots` | 条件選択を開く |
| 月表示で `s` | 条件選択を月表示の上に開く。候補一覧を閉じても月表示はそのまま残る |

**条件選択**:

```text
╭─────────────── 空き枠を探す ───────────────╮
│ 時間帯                                     │
│>● 09:00 ~ 18:00                            │
│ ○ 09:00 ~ 23:00                            │
│ 所要時間                                   │
│ ○ 30分                                     │
│ ● 1時間                                    │
│ ○ 1時間30分                                │
│ ○ 2時間                                    │
│ 週                                         │
│ ● 11/15(日)~11/21(土)                      │
│ ○ 11/22(日)~11/28(土)                      │
╰ <Space>:選択 <CR>:検索 <Esc>:閉じる q:隠す ╯
```

| 操作 | 振る舞い |
| --- | --- |
| `j` / `k` | 選択できる行（見出しを除く）を移動する。`>` が現在行を示す |
| `<Space>` | 時間帯・所要時間の行ではその項目に切り替える（1 つだけ `●`）。週の行では選択を反転する（複数 `●`） |
| `<CR>` | 選んだ条件で候補一覧を開く。週が 1 つも選ばれていなければ `Select at least one week` と警告し、開かない |
| `?` | ヘルプを開く |
| `<Esc>` | 条件選択を閉じる |
| `q` | 条件選択を含むすべての float を隠す |

- 週の行は今日を含む週から `slots.weeks` 週分（既定 8 週）を並べる。週の開始曜日は `week_start` に従う
- 週の表記は `MM/DD(曜)~MM/DD(曜)`。開いた直後は今日を含む週だけを選んだ状態にする
- 時間帯の既定は `slots.default_time_range`、所要時間の既定は `slots.default_duration` の行を選んだ状態にする
- 所要時間の表記は `30分` / `1時間` / `1時間30分`
- 候補一覧から戻ったときは、直前に選んだ条件を保つ

**候補一覧**:

```text
╭─ 空き枠 ──────────────────────╮╭─ 2026/11/16(月) ─────────────────────╮
│○ 2026/11/16(月) 09:00 ~ 10:00 ││ 08:00 │                              │
│● 2026/11/16(月) 12:00 ~ 13:00 ││       │                              │
│○ 2026/11/17(火) 09:00 ~ 18:00 ││ 09:00 │候補 09:00~10:00              │
│                               ││ 10:00 │ホンダ朝会       │daily-sta…  │
╰ <Space>:選択 a:全選択 y:コピー ─╯╰───────────────────────────────────────╯
```

| 操作 | 振る舞い |
| --- | --- |
| `j` / `k` | 候補を選択する。右のタイムラインを選択中の候補の日に描き直す |
| `<Space>` | 選択中の候補の選択状態を切り替える。カーソル行はオレンジの `○`、選択した行はオレンジの `●` で示す（カーソル行が選択済みなら `●`） |
| `a` | すべての候補を選択する。すべて選択済みなら全解除する |
| `y` | 選択中の候補だけを下記の形式でクリップボードへコピーし、`Copied N slots` と通知する |
| `?` | ヘルプを開く |
| `<Esc>` | 候補一覧（左右とも）を閉じ、条件選択に戻る |
| `q` | 候補一覧を含むすべての float を隠す。取得中に隠しても、届いた予定で候補を描き、表示し直すと見える |

- 開いた直後は左に `読み込み中...` を表示し、予定の取得が終わったら候補を表示する
- 候補が 0 件なら左に `空き枠なし` と表示し、タイムラインは空にする。`y` は何もコピーせず `No slots to copy` と通知する
- 候補はあるが 1 件も選択していないとき、`y` は何もコピーせず `No slots selected` と通知する
- 候補一覧の日付には曜日を付ける（例: `2026/11/16(月)`）。コピーする文字列は従来どおり曜日を付けない

**コピーの形式**（選択中の候補だけを、候補一覧の順で。行末に改行を付けず、行の間だけ改行で区切る）:

```text
2026/11/16 09:00 ~ 10:00
2026/11/16 12:00 ~ 13:00
2026/11/17 09:00 ~ 18:00
```

**候補の求め方**:

1. 選んだ週の日付のうち、`slots.weekdays` に含まれる曜日の日を対象にする（既定は毎日）
2. 対象の日ごとに、選んだ時間帯（例: 09:00〜18:00）を探索範囲にする
3. 「埋まっている予定」の開始の `slots.buffer` 分前から、終了の `slots.buffer` 分後までを（既定 60 分）探索範囲から除く
4. 残った連続する空き時間のうち、長さが所要時間以上のものを 1 件の候補にする。候補の開始・終了は空き時間の両端をそのまま使い、所要時間ぴったりには切らない
5. 今日は、現在時刻を 30 分単位に切り上げた時刻より前を除く。今日より前の日は対象にしない
6. 日付の昇順、同じ日は開始時刻の昇順に並べる

「埋まっている予定」は、取得した予定のうち次のすべてを満たすものとする。

- 時刻指定の予定である（終日予定は除く）
- `status` が `cancelled` でない
- `transparency` が `transparent`（「空き時間」表示）でない
- 自分（`attendees[].self == true`）の `responseStatus` が `declined` でない

日をまたぐ時刻指定の予定は、またいだ先の日の探索範囲も塞ぐ。

**タイムライン**:

- タイトルに `YYYY/MM/DD(曜)` を表示する
- その日の終日予定は winbar（ウィンドウ上端の固定行）に、時刻の列に `終日` と本文から続く薄いグレーの縦線を置き、候補と同じ列から右端までをカレンダー色のラベルで埋めて表示する。複数あるときは、時間の重なる予定と同じ規則で幅を分け合う。スクロールしても見えるようにするため、タイムラインの行には置かない。終日予定がない日は `終日` に続けて `なし` と表示する。winbar の背景は本文と同じ float の背景（`NormalFloat`）にする
- 1 行を 30 分とし、00:00〜24:00 の 48 行を描く。正時の行の左端に `HH:00` を表示し、その右に薄いグレーの縦線（`GoogleCalendarSlotRuler`）を引く。ウィンドウが 48 行より高い場合は、時刻の縦線 `│` だけの行を足して下端まで伸ばす
- 「埋まっている予定」をカレンダー色の背景（`GoogleCalendarCalendarBg*`）でブロック状に描き、1 行目にタイトル、2 行目に `HH:MM~HH:MM` を置く。1 行しかない予定は `タイトル HH:MM~HH:MM` を 1 行に収める
- Google カレンダーと同じく、各時間の最後の行（`HH:30` の行）に薄いグレーの横線（`GoogleCalendarSlotHourLine`）を引く。横線は予定と候補のブロックが無い部分にだけ引き、ブロックの上には引かない
- 時間の重なる予定は横に並べる。列の間に 1 列の隙間を置き、残りの幅を等分する（端数は最後の列に足す）。予定のブロックの右端は候補のブロックの右端と揃える
- 選択中の候補は `GoogleCalendarSlotCandidate` の背景で `候補 HH:MM~HH:MM` として描く
- 候補の開始の 4 行前（2 時間前）が先頭に来るようにスクロールし、前の予定が見えるようにする。ただし 24:00 の行が見えて下が余る位置になる場合は、ウィンドウが行で埋まる位置まで戻す

**予定の取得**:

- `primary` と `calendars` のすべてのカレンダーから、選んだ週の最初の日の前日 00:00 から最後の日の翌々日 00:00 までの予定を取得する。前後 1 日を足すのは、日をまたぐ予定と前日・翌日の予定の `buffer` を反映するため
- 月表示のキャッシュ（`state.month_cache`）と月表示の状態（`state.events_by_date` / `state.selected_date`）は読み書きしない。候補一覧を閉じた後の月表示の内容を変えないため
- `<Esc>` で閉じた後に届いた応答は捨てる（要求 ID で判定する）

## 設定

```lua
require('google-calendar').setup({
  slots = {
    -- 時間帯の選択肢（'HH:MM-HH:MM'。終了は 24:00 まで）
    time_ranges = { '09:00-18:00', '09:00-23:00' },
    default_time_range = '09:00-18:00',
    -- 所要時間の選択肢（分）
    durations = { 30, 60, 90, 120 },
    default_duration = 60,
    -- 埋まっている予定の前後に空ける時間（分）
    buffer = 60,
    -- 条件選択に並べる週の数
    weeks = 8,
    -- 候補を出す曜日
    weekdays = { 'sunday', 'monday', 'tuesday', 'wednesday', 'thursday', 'friday', 'saturday' },
    -- 候補一覧（左右の合計）のサイズ。ボーダーを除く利用可能領域に対する割合
    width = 0.8,
    height = 0.8,
  },
})
```

| キー | 取りうる値 | 不正な値のとき |
| --- | --- | --- |
| `time_ranges` | `'HH:MM-HH:MM'` の配列（開始 < 終了、終了は `24:00` まで） | 警告し、既定の配列を使う |
| `default_time_range` | `time_ranges` の要素の 1 つ | `time_ranges` の先頭を使う（警告しない） |
| `durations` | 1 以上の整数（分）の配列 | 警告し、既定の配列を使う |
| `default_duration` | `durations` の要素の 1 つ（分） | `durations` の先頭を使う（警告しない） |
| `buffer` | 0〜1440 の整数（分） | 警告し、60 を使う |
| `weeks` | 1〜52 の整数（週） | 警告し、8 を使う |
| `weekdays` | `'sunday'`〜`'saturday'` の 1 つ以上の配列 | 警告し、毎日を使う |
| `width` / `height` | 0 より大きく 1.0 以下の割合 | 指定値をそのまま使う（ほかの画面サイズと同じ） |

## API

該当なし（HTTP API を持たない）。予定の取得は既存の `gws.list_events` を使う。

## エッジケースの決定

- **空・最小データ**: 予定が 1 件もない日は時間帯全体が 1 件の候補になる。候補が 0 件なら `空き枠なし` を表示する
- **上限・境界値**: 空き時間の長さが所要時間とちょうど同じなら候補にする。予定の終了 + `buffer` と次の予定の開始 − `buffer` が一致する場合（空き 0 分）は候補にしない。時間帯の終了 `24:00` は表示も `24:00` とする
- **端数**: 予定の開始・終了が 10:15 のような端数でも丸めない（`buffer` 60 分なら 11:15 から空き）。丸めるのは今日の現在時刻だけ（30 分単位に切り上げ）
- **エラー時に利用者へ見えるもの**: 予定の取得に失敗したら既存のエラー通知（`notify.error`）を出し、候補一覧を閉じて条件選択に戻る
- **並行操作・二重実行**: 取得中に `<Esc>` で閉じた場合や、もう一度 `<CR>` で検索した場合は、古い要求の応答を捨てる
- **再表示時の整合**: 候補一覧は開くたびに予定を取得し直す。月表示のキャッシュとは共有しない
- **クリップボード**: `vim.fn.has('clipboard') == 0` か `config.clipboard` が失敗した場合は `Could not copy to clipboard` と通知する
