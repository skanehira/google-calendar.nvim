# 月表示

- 種別: 機能設計書
- 対象 UC: UC-001 (docs/design/USECASES.md)

## 何を作るか

Google カレンダーの月表示を Neovim の float window に描画する。月タイトル、曜日ヘッダー、6 週×7 日の日付セル、セル内の予定チップ（最大 3 件、超過は `+N`）を表示し、`h` / `l` / `j` / `k` で日を移動、`H` / `L` で前月・次月、`t` で今日へ移動する。`:GoogleCalendar [YYYY-MM]` で開く。予定の取得は `gws` の `events.list` を `singleEvents=true` で呼び、`nextPageToken` があれば追加取得する（[DESIGN.md](../DESIGN.md)「既知の制約」参照）。

## 入出力と振る舞い

**画面レイアウト**:

```text
┌─ Google Calendar — 2026年10月 ─────────────────────────────┐
│ 日    月    火    水    木    金    土                      │
│  28    29    30     1     2     3     4                     │
│  10:00 定例  14:00 レビュー                                 │
│  28    29    30     1     2     3     4                     │
│ ...                                                         │
│ h/l:日  j/k:週  H/L:月  t:今日  Enter:アジェンダ  a:登録  ?:ヘルプ │
└─────────────────────────────────────────────────────────────┘
```

**操作 → 振る舞い**:

| 操作 | 振る舞い |
| --- | --- |
| `:GoogleCalendar` | 当月の月表示を開く。既に開いている場合は再取得してフォーカスする |
| `:GoogleCalendar 2026-11` | 指定した月の月表示を開く。不正な形式は通知して開かない |
| `h` / `l` | 選択日を前日 / 翌日へ移動する。月の境界を越える場合は表示月も切り替える |
| `j` / `k` | 選択日を前週 / 翌週へ移動する。月の境界を越える場合は表示月も切り替える |
| `H` / `L` | 前月 / 次月へ移動し、選択日は同じ日付（存在しない場合は月末）にする |
| `t` | 今日を含む月へ移動し、今日を選択する |
| `<CR>` | 選択日の日別アジェンダを開く（[event-detail.md](event-detail.md)） |
| `a` | 選択日の登録フォームを開く（[event-create.md](event-create.md)） |
| `r` | 表示中の月を再取得する |
| `?` | ヘルプを開く（[help.md](help.md)） |
| `q` / `<Esc>` | 月表示を閉じ、元のウィンドウへ戻る |

**描画の決定**:

- float のサイズは `win_width = min(120, floor(columns * config.width))`、`win_height = min(40, floor(lines * config.height))`。設定 `width` / `height` は画面に対する割合として扱い、上限を適用する
- セル幅は `cell_w = floor((win_width - 6) / 7)`。7 セルを `│` で区切る
- 各週は「日付行 1 行 + 予定行 `max_events_per_cell + 1` 行」のブロック。予定行は `virt_lines` で描画し、7 セル分のチャンクを横に並べる
- 日付行は ` 1`〜`31` の右寄せ。今日は `GoogleCalendarToday`、選択日は `GoogleCalendarSelected`（セル全体・目立つ背景・bold）、日曜は `GoogleCalendarSunday`、土曜は `GoogleCalendarSaturday`、前月・翌月は `GoogleCalendarOtherMonth` でハイライトする
- ウィンドウの高さは「ヘッダー 1 行 + 6 週分の日付行 + 予定行」、幅は 7 セル + 6 本の区切り線に合わせる。下部・右側に空白を残さない（設定 `width` / `height` は上限）
- 月タイトルは `FloatTitle`、float のボーダーは `FloatBorder` を `winhl` で `GoogleCalendarHeader` / `GoogleCalendarBorder` に割り当てる。予定チップは `GoogleCalendarEvent` を背景に適用する
- 選択中のセルは左端に `>` マーカーを表示し、ウィンドウタイトルにも `選択: MM-DD` を表示する（背景色だけに頼らず、どの日が選択中かを判別できるようにする）
- 予定チップは `HH:MM タイトル`。終日予定は `終日 タイトル`。タイトルはセル幅に合わせて `…` で切り詰める
- 予定が `max_events_per_cell` を超える日は、`max_events_per_cell` 件までを表示し、最後の行に `+N` を表示する
- 予定がない日は予定行を描画しない（空行も描画しない）
- ヘッダーに `読み込み中...` を表示し、取得中はキー操作を無視する
- 予定の並び順は終日予定を先頭、その後を開始時刻の昇順にする

**データ**:

- 取得範囲は月初を含む週の開始曜日から 42 日。`timeMin` は範囲の 0 時、`timeMax` は範囲の翌日 0 時（ローカルオフセット付き RFC3339）
- 時刻付き予定は開始日に、終日予定は開始日から終了日の前日まで各日に載せる
- 予定は `events_by_date` に `YYYY-MM-DD` をキーとして保持する

キーマップは `config.keymaps.month` から解決し、`setup()` で上書きできる。閉じる `q` / `<Esc>` は `month.close` / `month.esc_close` で別々に変更・無効化できる。

## エッジケースの決定

- **空・最小データ**: 予定が 0 件の月は、日付セルのみを描画し、エラーにしない。予定行は描画しない
- **上限・境界値**: 月初が日曜の場合は 1 週目が月初から始まる。月初が月曜以降の場合は前月の日を埋める。常に 6 週（42 日）を描画する。2 月・閏年・30 日の月も同じ計算で扱う。セル幅が 7 未満になる場合は描画を諦め、`ウィンドウが狭すぎます` と通知する
- **エラー時に利用者へ見えるもの**: gws の API エラー時はエラー内容を通知し、取得済みの表示があれば維持する。初回で失敗した場合は空の月表示を開かず、通知だけを出す
- **並行操作・二重実行**: 取得中は `loading = true` としてキー操作を無視する。月移動を連続で行った場合は最後の要求だけを反映する（要求 ID を保持し、古い応答を破棄する）
- **再表示時の整合**: `r` または予定の変更後に表示中の月を再取得する。再取得後も選択日を維持する。他者による変更は `r` で反映する
